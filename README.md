# Dipan Design OS Showcase

Private, Pages-ready static showcase for Dipan's personal design operating system.

## Preview

```bash
python3 -m http.server 4173
```

Open http://localhost:4173/.

## Contents

- `research/DIPAN-DESIGN-OS.pdf` - designed 40-page report
- `research/DIPAN-DESIGN-OS.md` - complete Markdown source
- `research/SOURCES.md` - source ledger
- `research/dark-design-245-audit.csv` - full audit dataset
- `skill/` - reusable personal skill and references

## Publication

The repository must remain private. The static build is compatible with GitHub Pages, but public Pages must not be enabled without Dipan's explicit approval.
